\# Customer Sales Prediction System



A machine learning-based Customer Sales Prediction System developed using Python and Flask. The project uses customer and sales-related information to analyze customer behavior and generate sales predictions through a web-based application.



\## Project Overview



The Customer Sales Prediction System is designed to help analyze customer-related sales data and provide predictions using a machine learning model.



The project includes:



\- Data preprocessing

\- Exploratory data analysis

\- Feature preparation

\- Machine learning model development

\- Model prediction

\- Flask-based web application

\- Customer sales dataset

\- Jupyter Notebook implementation



\## Technologies Used



\- Python

\- Pandas

\- NumPy

\- Scikit-learn

\- Flask

\- Jupyter Notebook

\- HTML

\- CSS

\- Git \& GitHub



\## Dataset



The project uses a customer sales dataset containing \*\*500 records and 31 KPIs/features\*\*.



The dataset contains customer and sales-related information that can be used for prediction and analysis.
